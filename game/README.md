# Цветной рейс

Головоломка про парковку и пассажиров (2D-прототип, 3 уровня).

- Нажми на машину: она поедет по стрелке, если путь до края поля свободен.
- Уехавшая машина встаёт на свободное место, и в неё садятся пассажиры её цвета.
- Полная машина уезжает и освобождает место.
- Проигрыш: все места заняты, а следующему пассажиру не подходит ни одна машина.
  Один раз за уровень можно открыть пятое место.

## Запуск

Открой `index.html` в браузере (рядом должен лежать `engine.js`).

## Почему каждый уровень решается

Уровни генерируются из фиксированных seed в `engine.js`:

1. Машины ставятся по одной; новая принимается, только если поле всё ещё можно разобрать полностью.
2. По порядку разбора строится очередь пассажиров. Пассажиров каждого цвета ровно столько,
   сколько мест в машинах этого цвета (вместимость: 2 клетки — 4 места, 3 клетки — 6 мест).
3. Уровень проигрывается симулятором по правилам игры; если решения нет, берётся следующий seed.

Проверка: `node game/test.js`.
